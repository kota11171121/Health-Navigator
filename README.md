# Health Navigator

# アプリの概要

生活習慣病予防を目的とした健康管理アプリケーション<br>
自身の身長、体重等の情報や日々の運動の量などを記録すると、そのデータをもとに一人一人に合わせた具体的なアドバイスができる<br>
PCでの使用を前提としたデスクトップアプリ<br>

# アプリの使用技術

開発言語 Python<br>

開発環境 Visual Studio Code<br>

__個別にダウンロードが必要なライブラリ__<br>

customtkinter<br>
pandas<br>
matplotlib<br>
google-genai<br>
tkcalendar<br>

# アプリの機能

自身の身長・体重などの基本的なプロフィールの入力をする機能<br>
運動した時間の記録と管理ができる機能<br>
記録した毎日の運動量に応じたグラフを作成する機能<br>
記録したデータを使ったAIによる自分だけの健康アドバイスができる「AIからのアドバイス」機能<br>
※「AIからのアドバイス」を利用したい場合の注意点は後述※<br>

# 実行方法

GitHubからダウンロードした後、ファイルの解凍、展開を行う<br>
requirements記述の必要なライブラリをダウンロード<br>
main.pyを実行<br>

# 使用時の注意

__AIのアドバイス機能について__<br>
Google GeminiのAPIのkeyが、プログラム上のファイル「gemini_api.py」の5行目の　api_key = ""　に入力されていないと「AIからのアドバイス」ではなく「健康アドバイス」となり、AIのアドバイスではなく、現在のデータを利用し判定したアドバイスとなります
